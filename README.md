# 💬 AstrBot 语录核心插件 (Quote Core)

> 支持手动收录 / 随机抽卡 / AI 点评 / 高清长图渲染

一个面向群聊的语录插件，支持回复收录、随机抽取、戳一戳触发，以及基于 LLM 的手动收录点评。

---

## ✨ 功能特性

- **📥 手动收录**
  - 回复某条消息，快速收录到语录库
  - 自动去重（同群同文本）
  - 自动过滤命令消息、链接消息、黑名单用户、机器人自身消息
  - 可选后台 AI 点评，收录成功提示会优先返回

- **🃏 随机语录抽卡**
  - 支持单条随机
  - 支持批量抽取并合成长图
  - 支持按 @用户 定向抽取

- **🎨 高清渲染**
  - 使用 HTML/CSS + Playwright 生成高质量图片
  - 自动拉取 QQ 头像
  - 支持单卡/合集长图样式

- **👆 戳一戳触发**
  - 可配置“关闭 / 仅戳Bot / 任意戳”
  - 命中后触发随机语录逻辑

---

## 📦 依赖要求

- Python 依赖：
  - `aiohttp>=3.8.0`
  - `playwright>=1.40.0`
- 需要安装 Chromium（Playwright）：
  ```bash
  playwright install chromium
  ```
- 协议端：**OneBot V11 (aiocqhttp 兼容)**  
  > `收录` 依赖 OneBot API（如 `get_msg` 等）

## 🚀 指令说明

> 以下以 `/` 为示例，是否必须前缀取决于 `ignore_prefix` 配置。

| 指令 | 说明 |
|---|---|
| `/收录` | **需回复一条消息**，将该消息文本收录为语录 |
| `/语录` | 随机抽取 1 条语录 |
| `/语录 5` | 随机抽取 5 条语录（合成长图） |
| `/语录 @某人` | 随机抽取该用户 1 条语录 |
| `/语录 @某人 5` | 随机抽取该用户 5 条语录 |
| `/删除` | **回复某条由Bot发送的语录卡片**，删除该条语录（未回复时回退删除本群上一条）|

---

## ⚙️ 配置项（`_conf_schema.json`）

- `user_blacklist`：全局黑名单 QQ 列表
- `poke_mode`：戳一戳模式（关闭 / 仅戳Bot / 任意戳）
- `manual_ai_comment_enabled`：开启后手动收录会在后台补充 AI 点评
- `llm_provider_id`：AI 点评使用的模型提供器 ID（留空则不调用 LLM）
- `max_batch_count`：`/语录 N` 最大数量限制
- `ignore_prefix`：开启后可无前缀触发（如直接发“语录”）
- `global_mode`：全局语录池抽取模式（跨群抽取/展示来源群）
- `admin_only`：仅 Bot 管理员可使用 `/删除`

---

## 🧠 AI 点评说明

开启 `manual_ai_comment_enabled` 后，执行 `/收录` 时插件会：

1. 先完成语录入库并发送收录成功提示
2. 在后台构造 Prompt 调用已明确配置的 LLM
3. 将模型返回的点评作为评论补充到该条语录

---

## 🗂️ 数据存储

- 存储目录：`quotes_by_group/<群号>.json`
- 兼容旧数据：首次发现旧版 `quotes.json` 时会按 `group` 字段自动拆分到 `quotes_by_group`
- 写入策略：临时文件 + 原子替换，避免写坏
- 去重索引：内存哈希索引（`group + text`），查询 O(1)

---

## ⚠️ 注意事项

- `/收录` 当前仅收录**纯文本**内容（非文本消息不会入库）。
- `ignore_prefix=true` 时，插件会尝试识别并避开其他插件命令，降低误触发概率。
- `/删除` 现支持**回复指定语录卡片精确删除**；未回复时回退为删除本群最近一次发送的语录。
- 首次使用 Playwright 渲染前请确保已安装 Chromium。
